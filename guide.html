LP Run Guide

How to use the LP Run app before and during the race.

For lap counters Before race setup During race taps Finish + partial lap
Before the race

1. Get set up

1

Open the app early

Load the LP Run app before the race starts so your phone is awake, the page is ready, and you are not scrambling at the horn.

2

Enter runner details

Put in the runner’s full name. Add age, division, optional gender, and Masters eligibility if needed. The app will auto-fill age group.

3

Pick the correct lane

Choose Lane 1 or Lane 5. The app uses fixed lap distance rules, so the lane must be right before you begin.

4

Double check duration

The event duration should usually be set to 33:20 unless the race director says otherwise.

Important: one lap counter should focus on one runner. Your whole job is taps, not multitasking, not social hour, not advanced philosophy.
When the race starts

2. Count laps

1

Press Start at the beginning

Start the timer as the race begins. After that, the app shows elapsed time, countdown, laps, and split data.

2

Tap Lap every crossing

Each time your runner completes a full lap and crosses the line, tap the big Lap button once.

3

Use Undo only for mistakes

If you accidentally add a lap, use Undo Lap right away. Do not use it casually. It is for actual tap errors.

4

Do not change setup mid-race

Once the race is rolling, leave the runner details and lane alone unless you are resetting before a fresh attempt.

Tip: if you are unsure whether the runner completed the lap, wait for the clear crossing. Clean taps beat guess taps.
At the horn

3. Handle the finish correctly

1

When time is up, stop tapping laps

At the horn, full lap counting is done. The app will prompt you to enter the partial lap.

2

Go to the runner

Physically go down to the runner you are tracking and find the distance past the last full lap.

3

Enter the partial distance

Type the extra distance after the horn and choose the correct unit, feet or meters.

4

Finalize the result

Use Finalize Result once the partial is correct. This locks the official data so stray taps do not mess up the finish.

Do not skip the partial. If the runner ended halfway down the track, that missing distance matters.
Submit flow

4. Save and share

1

Press Submit + Share

The app first tries to save the result to the Google Sheet, then prepares a share summary and CSV.

2

Read the confirmation prompts

You will be asked if you are really ready to submit and whether the partial was entered. This is your last double check.

3

Use test mode only for testing

If you check “Mark this as a test submission,” the app will flag the row in Notes so it can be identified later.

4

If the network fails, do not panic

The app keeps the pending result on the device and can retry later. The status box will tell you whether it saved successfully.
